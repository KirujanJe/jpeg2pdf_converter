# jpeg2pdf_converter
A simple static web application that converts JPEG images into PDF files, supporting both Letter and A4 page formats. All file processing happens entirely on the client side, ensuring a secure and private conversion process. Built using HTML, CSS, JavaScript, and the jsPDF library.

Built for a desktop environment. Currently not mobile ready. 

Version 1 of this website was completed in December, 2024. An update in the future will include more features (i.e. support more file formats, better file size compression, etc) and fix all bugs.
